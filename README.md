## Project Overview

This project implements a comprehensive digit detection and classification system for MNIST-style images, progressing from basic CNN classification to advanced object detection using Feature Pyramid Networks (FPN).

The system consists of **4 progressive tasks**, each building upon previous work to create increasingly sophisticated detection capabilities.
